Visual Accessibility Guide

Helping Everyone Access Visual Information

Not everyone sees a screen in the same way. Some people have low vision, difficulty telling colors apart, or use screen readers to access content. Visual accessibility helps make sure information stays understandable in different situations.

Use meaningful image descriptions

Add alternative text to images that share important information. This gives screen reader users a way to understand what an image communicates.

Keep text easy to read

Choose readable fonts, clear spacing, and layouts that still work when someone zooms in or increases text size.

Do not use color alone

Pair colors with labels, icons, or clear messages. A red border by itself should not be the only sign that a form has an error.

Use clear headings and links

Organized headings and descriptive links help people understand and navigate a page, including those using assistive technology.

Everyday Example

Instead of showing only a red warning icon, write: “Please enter your email address.” The message explains what needs to be fixed without depending on color.

Key Takeaway

Visual accessibility is about making information clear, readable, and available beyond what someone can see.
