Physical Accessibility Guide

Making Websites Easier to Navigate

Some people cannot comfortably use a mouse or touchscreen. They may prefer a keyboard, voice control, switches, or other assistive tools. Physical accessibility makes it possible to interact with a website in different ways.

Support keyboard navigation

Important links, buttons, and forms should work without requiring a mouse.

Show keyboard focus clearly

When someone presses Tab, they should be able to see which button or link is currently selected.

Make controls easy to use

Buttons and links should be easy to identify and have enough space around them.

Allow different input methods

Avoid interactions that work only with one device or one type of gesture.

Give people enough time

Avoid unnecessary time limits, especially for reading instructions and completing forms.

Everyday Example

A visitor should be able to open a menu, choose an accessibility topic, and submit a form using only the keyboard.

Key Takeaway

Physical accessibility gives people more than one way to move around and use a website.
